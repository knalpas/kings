# Sceptre · Trees of kings

Zoomable genealogical trees of the kings of **France** and **England**, in the same historic gallery spirit as [Atelier](https://knalpas.github.io/atelier/).

**Live:** https://knalpas.github.io/kings/

## Features

- Toggle **France / England** at the top
- Pan & zoom the family tree (scroll, pinch, or +/- controls)
- Tap a monarch for reign dates, dynasty, summary, and Wikipedia
- Dashed nodes mark non-reigning links that connect the bloodline
- Colour legend by royal house

## Develop

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Uses the `gh-pages` branch. Vite `base` is `/kings/` for `https://knalpas.github.io/kings/`.
